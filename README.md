# Leaful — GitHub Pages

A static site with home, support, and privacy policy pages for Leaful.

## Before publishing

1. Replace `REPLACE_WITH_YOUR_EMAIL@example.com` with a real support email in `support.html` and `privacy.html` (including `mailto:` links).
2. **IMPORTANT:** Review `privacy.html`, especially the **Third-party services and data collection** section. Remove developer-action wording only after checking your actual iOS app and all embedded SDKs. App Store Connect answers must match your real data practices.
3. Update the owner/copyright text if applicable.

## Upload and publish

1. Create a new public repository called `leaful-site` (or your preferred name) on github.com.
2. Upload `index.html`, `support.html`, `privacy.html`, `styles.css` and `.nojekyll` to the **repository root** (not inside an extra directory). Commit changes.
3. Open repository **Settings → Pages → Build and deployment → Source: Deploy from a branch**, then choose `main` and `/(root)`, then Save.
4. Open `https://YOUR_USERNAME.github.io/leaful-site/` after GitHub Pages finishes deployment.

## App Store URLs

- Support URL: `https://YOUR_USERNAME.github.io/leaful-site/support.html`
- Privacy Policy URL: `https://YOUR_USERNAME.github.io/leaful-site/privacy.html`
- Marketing URL (optional): `https://YOUR_USERNAME.github.io/leaful-site/`

Replace `YOUR_USERNAME` with your exact GitHub account username. If you choose a different repo name, use that instead of `leaful-site`.
